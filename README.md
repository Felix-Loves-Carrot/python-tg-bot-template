# python-tg-bot-template

Минималистичный асинхронный шаблон Telegram-бота на **Python** (`aiogram 3` + `aiosqlite`), подготовленный для быстрого запуска MVP на хакатонах.

## Стек
- **Python 3.11+**
- **aiogram 3.x** (асинхронная обработка апдейтов и роутеры)
- **aiosqlite** (асинхронная работа с SQLite)
- **python-dotenv** (управление переменными окружения)

## Быстрый старт
```bash
git clone https://github.com
cd python-tg-bot-template
pip install -r requirements.txt
cp .env.example .env
python bot.py
```
